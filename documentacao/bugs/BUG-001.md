# BUG-001 — Menor recebendo receita: esperado HTTP 400, ocorre 500

## Onde está documentado nos testes

- Integração: **`tests/api/MinhasFinancas.Tests.Integration/Controller/TransacoesControllerTests.cs`**

## Comportamento esperado

**`POST`** de uma **receita** para uma **menor de idade** → resposta **400 Bad Request** (regra de negócio), sem gerar erro interno do servidor.

## Comportamento observado

Na implementação atual, a API pode responder **500 Internal Server Error** em vez de **400**.

## Como reproduzir

Executar o teste de integração indicado abaixo ou rodar a suite de integração completa. O corpo do pedido é **`POST /api/v1.0/transacoes`** com tipo receita e **`pessoaId`** de menor (seed de teste).

## Evidência (teste automatizado)

**`TransacoesControllerTests.Receita_para_menor_deve_retornar_bad_request`** — permanece falhando enquanto o status HTTP não for **400**.

## Critério de resolução

O teste passa quando a resposta for **400 Bad Request**.
