# BUG-003 — Exclusão de pessoa e transações relacionadas (cascade)

## Cobertura em testes

Integração — **`tests/api/MinhasFinancas.Tests.Integration/Controller/PessoasControllerTests.cs`**

- **`Exclusao_de_pessoa_deve_remover_transacoes_relacionadas`**

## Comportamento esperado

Ao excluir uma pessoa pelo **`DELETE /api/v1.0/Pessoas/{id}`**, não deve permanecer transação com esse **`pessoaId`** na base coberta pela API.

## Comportamento observado

Transações órfãs ou integridade inconsistente.

## Convenção JSON

**`tipo`**: **`0`** = despesa.

## Como reproduzir (Swagger)

1. **`http://localhost:5000/swagger/index.html`** — **v1.0**.
2. **`GET /api/v1.0/Pessoas`**: copie **`id`** de **`Maria Santos`**.
3. **`GET /api/v1.0/Categorias`**: copie **`id`** da categoria **`Alimentação`**.
4. **`POST /api/v1.0/Transacoes`**:

```json
{
  "descricao": "Reprodução BUG-003 — vínculo com Maria",
  "valor": 99,
  "tipo": 0,
  "categoriaId": "COLE_AQUI_GUID_ALIMENTACAO",
  "pessoaId": "COLE_AQUI_GUID_MARIA_SANTOS",
  "data": "2026-05-07T15:00:00"
}
```

Execute **→ 201**.

5. **`DELETE /api/v1.0/Pessoas/{id}`** com o mesmo GUID de **Maria Santos** → **Execute** (**204** se a cascata estiver correta).
6. **`GET /api/v1.0/Transacoes`** com `page` **1** e **`pageSize`** alto → confirmar que **não** há **`pessoaId`** de Maria nos **`items`**.
