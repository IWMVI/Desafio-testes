# BUG-002 — Tipo da transação incompatível com a finalidade da categoria

## Regra / contrato

Ao criar **`POST /api/v1.0/Transacoes`**, **despesa** em categoria **só receita** ou **receita** em categoria **só despesa** deve responder **400 Bad Request**.

## Comportamento esperado

**400**.

## Comportamento observado

Muitas vezes **500** ou até **201** indevido.

## Cobertura em testes

- **`Despesa_com_categoria_apenas_receita_deve_retornar_bad_request`**
- **`Receita_com_categoria_apenas_despesa_deve_retornar_bad_request`**
- **`Receita_com_categoria_ambas_deve_ser_permitido`**
- **`Despesa_com_categoria_ambas_deve_ser_permitido`**

## Convenção JSON

- **`tipo`**: **`0`** = despesa · **`1`** = receita.
- Seed: **`Salário`** = apenas receita; **`Alimentação`** = apenas despesa.

## Como reproduzir (Swagger)

1. **`http://localhost:5000/swagger/index.html`** — **v1.0**.
2. **`GET /api/v1.0/Pessoas`**: **`id`** de **`João Silva`**.
3. **`GET /api/v1.0/Categorias`**: copie GUIDs de **`Salário`** e **`Alimentação`**.

### Cenário A — despesa + categoria só receita (esperado **400**)

4. **`POST /api/v1.0/Transacoes`**:

```json
{
  "descricao": "BUG-002-A despesa com categoria receita apenas",
  "valor": 10,
  "tipo": 0,
  "categoriaId": "COLE_GUID_SALARIO",
  "pessoaId": "COLE_GUID_JOAO_SILVA",
  "data": "2026-05-07T15:00:00"
}
```

### Cenário B — receita + categoria só despesa (esperado **400**)

5. **`POST /api/v1.0/Transacoes`**:

```json
{
  "descricao": "BUG-002-B receita com categoria despesa apenas",
  "valor": 10,
  "tipo": 1,
  "categoriaId": "COLE_GUID_ALIMENTACAO",
  "pessoaId": "COLE_GUID_JOAO_SILVA",
  "data": "2026-05-07T15:00:00"
}
```

**Defeito:** **500** ou **201**. **Correto:** **400**.

### (Opcional) Teste de integração

```powershell
dotnet test tests/api/MinhasFinancas.Tests.Integration/MinhasFinancas.Tests.Integration.csproj `
  --filter "FullyQualifiedName~Despesa_com_categoria_apenas_receita|FullyQualifiedName~Receita_com_categoria_apenas_despesa|FullyQualifiedName~Receita_com_categoria_ambas|FullyQualifiedName~Despesa_com_categoria_ambas"
```

## Critério de resolução

Cenários incompatíveis devolvem **400** no Swagger; cenários com categoria **ambas** permitem **201**; os testes de integração passam.
