# BUG-004 — Excluir pessoa inexistente: esperado HTTP 404

## Onde está documentado nos testes

- Integração: **`tests/api/MinhasFinancas.Tests.Integration/Controller/PessoasControllerTests.cs`**

## Comportamento esperado

**`DELETE /api/v1.0/pessoas/{id}`** com **id** que não existe na base → **404 Not Found**.

## Comportamento observado

Na implementação atual, pode vir **204 No Content** ou outro código de sucesso inconsistente com recurso ausente.

## Evidência (teste automatizado)

**`PessoasControllerTests.Delete_de_recurso_inexistente_deve_retornar_not_found`**

## Critério de resolução

O teste passa quando o status HTTP for **404**.
